## 项目结构

- `stitchtv_core` 项目核心库，实现获取各个网站的信息及弹幕。
- `stitchtv_console` 基于stitchtv_core的控制台程序。
- `stitchtv_app` 基于核心库实现的Flutter APP客户端。
- `stitchtv_tv_app` 基于核心库实现的Flutter Android TV客户端。
